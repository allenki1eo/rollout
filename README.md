# Rollout

Rollout: 30-marble knockout. A Three.js game in one page.

Open `index.html` in a browser to play. Scripts and fonts live in `vendor/` and `fonts/`, so keep those next to the page. The game does not need a build step to run on GitHub Pages.

`node scripts/build.mjs` writes `dist/` and `rollout-crazygames.zip`. Upload that zip in the CrazyGames developer portal. Store text and cover images are in `store/`. Why the game plays the way it does is in `DESIGN.md`.
